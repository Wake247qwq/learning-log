## 踩到的坑

1. conda 要求先接受服务条款，我抄 URL 时少写了一个 s，程序提示"没有找到条款"而不是"没有接受"
2. 缺了 conda init，activate 命令执行后静默失效，提示符没有变化
3. 忘了先激活 brain，包装进了 base 环境
4. SSH 公钥在终端里折行，粘贴到 GitHub 报格式错误
5. 输入法占用了 Ctrl+Shift，VS Code 的命令面板打不开
6. VS Code 处于受限模式，扩展被禁用，状态栏看不到解释器
7. 新开的终端默认在用户主目录，git 报 not a git repository
8. README 建到了 C:\Users\Wake，不在项目目录里
